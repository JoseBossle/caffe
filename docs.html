Documentação Oficial

Manual técnico de referência, arquitetura de camadas e componentes do CAFFE Framework.

1. Instalação e Estrutura

Para iniciar um projeto utilizando o CAFFE 1.1, certifique-se de manter a estrutura de diretórios padronizada em letras minúsculas e inclua o arquivo centralizador no <head>:

<link rel="stylesheet" href="css/index.css">

2. Sistema de Camadas (@layer)

O CAFFE faz uso avançado da regra CSS @layer para controlar rigorosamente a especificidade do código semântico, evitando conflitos de estilos:

Core

Variáveis globais, custom properties, reset e tokens base de design.

Components

Elementos visuais reutilizáveis como botões, cards, modais e menus.

3. Automação JavaScript (Engine)

O motor minimalista opera inteiramente via delegação de eventos, eliminando a necessidade de bindings manuais por elemento[cite: 1, 2]. Importe-o como módulo no final do corpo da página:

<script src="javascript/basic/index.js" type="module"></script>
